# Descripción

Verificador académico de EPP de torso hacia arriba para controlar una solicitud de ingreso a obra. Captura con webcam USB y procesamiento local en Jetson Nano, señales y actuadores mediante ESP32-C6. Núcleo: casco y chaleco; gafas y guantes opcionales, sujetos a revalidación. Principio: "ante la duda, rojo". **Prototipo no certificado**.

**Alcance del repositorio inicial:** estructura de trabajo, código de ejemplo verificable en PC, ejemplo ESP-IDF, borrador de CRC y una interfaz estática. No hay control de acceso operativo.
